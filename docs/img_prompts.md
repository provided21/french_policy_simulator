# PPT 配图提示词

## 数据与基础设施流程图

一张流程图，按三个阶段从左到右排列：

第一阶段：探索数据
- 加载 HuggingFace 数据集，600万条法国用户画像
- 检查数据完整性（字段是否齐全、有无缺失）
- 验证数据合理性（年龄分布是否正常、职业分类是否合理）
- 确认数据可用后，进入下一阶段

第二阶段：检索
- 用 SBERT 模型（all-MiniLM-L6-v2）将 600 万条画像编码为向量，构建 FAISS 索引
- 输入政策问题后，用同一模型编码问题为向量
- 执行两种检索策略进行对比：
  - 语义检索：在 FAISS 中搜索与问题语义最相关的 10,000 人
  - 随机抽样：从全量数据中均匀随机抽取 10,000 人
- 对比两种策略的结果，确认语义检索更接近真实调查后，后续实验均采用语义检索

第三阶段：并行调用 LLM
- 对检索到的 10,000 条画像，逐条构建 Prompt（包含人口统计、社会背景、人格画像、兴趣爱好）
- 通过异步客户端并行调用 LLM（DeepSeek-V4-Flash，SiliconFlow API）
- 调用过程中做速率控制（RPM+TPM）、缓存去重（SQLite）、失败重试（指数退避）
- 解析回复，输出支持度分数和立场标签，存入数据库

三个阶段用箭头串联。所有文字使用中文。
