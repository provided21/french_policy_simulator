# Prompt 迭代记录：退休年龄问题

**问题**：您是否支持将法定退休年龄从64岁恢复到62岁？请给出0-10的支持度分数。

**IFOP 基准**（三选题）：回到62岁 61% / 维持64岁 34% / 进一步提高 5%

---

## Run 1 — 原始 Prompt

**日期**：2026-05-10（课程对话前）
**数据**：已删除（对话记录回溯）

**Prompt 要求部分**：
```
【要求】
1. 第一人称"我"视角
2. 用中文，简短精炼准确
3. 结合自身画像，真实自然
4. 尽量避免中立回答，应表达明确倾向（支持或反对）
5. 避免过度极端语气，理性客观
6. 结尾标注：支持度：X/10（0-10分）

示例：作为一名45岁男性工人，我认为...支持度：3/10
```

**结果**（来自对话记录）：

| 指标 | 值 |
|------|-----|
| 平均支持度 | 0.687 (6.87/10) |
| 支持（回到62岁） | ~89% |
| 中立（维持64岁） | ~10% |
| 反对（进一步提高） | ~1% |

**诊断**：严重偏向"回到62岁"（+28pp vs 基准61%）。
- 示例"工人 + 3/10"锚定了低分（实际工人最支持回62岁），模型可能反向模仿
- "尽量避免中立回答"鼓励了极端立场

## Run 3 — 严格基于画像 + 分数映射

**日期**：2026-05-11
**数据**：Query ID `20260511_003034`

**Prompt 要求部分**：
```
【要求】
1. 第一人称"我"视角
2. 用中文，简短精炼准确
3. 严格基于自身画像（年龄/职业/学历/省份/家庭状况）决定立场，而非你所知的"法国普遍民意"
4. 理性客观，避免极端语气
5. 结尾标注：支持度：X/10
   （0-3=进一步提高退休年龄 | 4-6=维持64岁 | 7-10=回到62岁）
```

改动（相对于 Run 2）：
- 砍掉了示例行
- 要求3+4 合并精简："结合自身画像"+"结合法国形势+摒弃内置价值观" → "严格基于自身画像…而非法国普遍民意"
- 新增分数区间映射说明
- 修复编号（1,2,3,4,5,7 → 1,2,3,4,5）

**结果**：

| 指标 | 值 |
|------|-----|
| 总请求数 | 10000 |
| 成功回答 | 8843 |
| 失败（限速等） | 1157 |
| 平均支持度 | 0.578 (5.78/10) |
| 支持（回到62岁） | 28.9% |
| 中立（维持64岁） | 70.9% |
| 反对（进一步提高） | 0.1% |

**评估**：矫枉过正。移除"法国形势"和示例后，模型过度收敛到中立区间。支持率从 72.8% 骤降至 28.9%（-32.1pp vs 基准）。反对几乎消失。
