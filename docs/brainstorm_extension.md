## 一、Prompt 工程实验矩阵（支撑"宏观拟合"）

系统性消融实验，对比不同设计维度的效果：

- **画像粒度实验**：完整画像 vs 仅人口统计 vs 仅人格特质
- **指令强度实验**：当前"尽量避免中立回答" → 对比「不施加立场引导」vs「强制选边」vs 当前方案
- **角色扮演框架对比**：
  - "你是一位法国公民"（当前）
  - "你是{name}，{age}岁，{occupation}"（更具体）
  - 不加角色扮演，直接问"一个{occupation}会怎么想"（第三人称）
- **语言实验**：法语 prompt vs 中文 prompt → 检验语言是否影响立场
- **Few-shot 校准**：在 prompt 中给出 1-2 个真实调查统计结果作为参考锚点

→ 可成为论文章节：*"Prompt 设计对模拟政策民调准确性的影响"*

## 二、真实调查数据对标（支撑"宏观拟合"）

### 数据源

| 机构 | 常见议题 | 可对标维度 |
|------|----------|------------|
| **IFOP** | 退休改革、移民、购买力 | 职业 × 支持度 |
| **Ipsos** | 总统大选、社会议题 | 年龄 × 地区 |
| **OpinionWay** | 能源政策、教育改革 | 学历 × 立场 |
| **INSEE** | 就业、收入满意度 | 官方统计数据 |

### 评估指标

- **分组支持度排序一致性**（Spearman 秩相关）：真实数据中"工人最反对，高管最支持"的排序是否复现
- **分布相似度**：KL 散度 / Wasserstein 距离
- **交叉维度偏差热力图**：模型是否系统性高估某类人的支持度

## 三、ML 建模

当前可用特征：`age, sex, marital_status, household_type, occupation, education_level, departement, similarity`
目标变量：`support_score`（回归）/ `stance`（分类）
文本侧：`llm_response`（原始回答）

### 可做的方向

- **可解释性分析**：SHAP / LIME 分析哪个特征对支持度影响最大
- **模型对比实验**：LR（baseline）→ XGBoost → MLP → 对比表格 + 学习曲线
- **跨政策泛化**：用"退休改革"数据训练的模型预测"教育改革"支持度
- **反事实推理**：SHAP partial dependence plot 回答"教育水平提高→支持度如何变"
- **交互效应检测**：年龄 × 职业交互效应 → Friedman's H-statistic

→ 学术价值点：*"LLM 模拟的个体级态度数据用于 ML 建模的可行性"*

## 四、文本分析

当前 `llm_response` 完整保留，可深挖：

| 分析类型 | 方法 | 能回答的问题 |
|----------|------|-------------|
| **情感分析** | VADER / TextBlob / CamemBERT | 情感分数 vs LLM 自报支持度一致性 |
| **主题建模** | BERTopic / LDA | 不同立场人群讨论的焦点话题差异 |
| **关键词差异** | TF-IDF + 卡方检验 | 支持者 vs 反对者用词差异 |
| **论证模式** | 正则 + 字典匹配 | 经济论证 vs 道德论证的群体偏好 |
| **响应长度分析** | 统计检验 | 高学历者是否写更长？反对者是否更详细？ |
| **立场一致性** | 交叉表 | LLM "支持度 X/10" vs 第三方情感分析的差异 |

## 五、前端可视化升级

当前仅 3 个 Tab，大作业展示可增加：

- **模型校准 Tab**：模拟结果 vs 真实调查数据并排对比图
- **ML 分析 Tab**：特征重要性、SHAP beeswarm、混淆矩阵、ROC 曲线
- **文本分析 Tab**：词云、情感分布、主题气泡图

- **导出功能**：一键下载 PDF 报告或导出 Excel/CSV

## 六、统计检验

- **多因素 ANOVA**：检验职业 × 学历对支持度的交互效应
- **事后检验 (Tukey HSD)**：哪个职业组之间差异显著
- **效应量 (Cohen's d / η²)**：不只是"显著"，还要看"多大"
- **Bootstrap 置信区间**：支持率 62.3% (95% CI: 59.8%–64.7%)

## 七、模型鲁棒性 / 可重复性测试

- **同 prompt 多次调用**：相同人物 + 相同问题 → 支持度方差 → LLM 稳定性
- **Temperature 敏感度**：T=0~2 扫描，看支持度分布偏移
- **检索噪声**：加入不相关人物 → 是否影响整体统计
- **偏见检测**：性别/地区系统性偏差检验

## 优先级建议

| 优先级 | 方向 | 理由 |
|--------|------|------|
| **P0** | 真实调查对标 + Prompt 实验 | 核心创新点，差异化竞争力 |
| **P0** | ML 建模 + SHAP 解释 | 契合课程要求，数据现成 |
| **P1** | 文本分析（情感 + 关键词） | 有原始回答，不做浪费 |
| **P1** | 统计检验 | 结论更严谨，代码量小 |
| **P2** | 前端整合 + 导出 | 展示效果好，但工作量较大 |
| **P2** | 鲁棒性测试 | 方法论完善，锦上添花 |
