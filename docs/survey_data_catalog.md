# 法国社会调查 — Prompt 优先级 & 对标数据

> 用途：为法国政策模拟器筛选可对标真实民调的 prompt，支撑 `brainstorm_extension.md` 中**宏观拟合**（对比 LLM 模拟分布 vs 真实民调分布）和**细粒度建模**（用画像特征预测个体态度）两条支线。

---

## 分类标准

| 方向 | 核心目标 | 对数据的要求 | 评估方式 |
|------|---------|-------------|---------|
| **宏观拟合** | LLM 模拟的群体分布能否复现真实民调 | 真实调查有**人口学交叉表**（性别×支持度、年龄×支持度等） | Spearman 秩相关、KL 散度、偏差热力图 |
| **细粒度建模** | 用 age/sex/occupation/education 等特征预测个体态度 | 目标变量清晰（二分/三分）+ **特征维度多** | LR / XGBoost / MLP + SHAP 可解释性 |
| **两者皆宜** | 既有外部交叉表可对标宏观分布，又有足够特征可做 ML | 以上两者兼具 | 宏观 → 微观双层验证 |

---

## 一、两者皆宜（宏观对标 + ML 建模）⭐

这些调查同时满足：(a) 有丰富的人口学交叉表可做宏观分布对比，(b) 目标变量为清晰的二分/三分，(c) 项目画像变量（age/sex/occupation/education/departement）可直接作为 ML 特征。

### 1. 退休年龄三选一：回到 62 / 维持 64 / 进一步提高

| | |
|---|---|
| **Prompt (FR)** | *"Que faudrait-il faire concernant l'âge légal de départ à la retraite ? Le ramener à 62 ans, le maintenir à 64 ans, ou l'augmenter davantage ?"* |
| **Prompt (ZH)** | 关于法定退休年龄，您认为应该怎么做？回到 62 岁、维持在 64 岁，还是进一步提高？ |
| **数据源** | `121521_presentation_ifop_cgt_retraites_2025.04.11-1-1.pdf` — IFOP/CGT, 2025.04, n=1,001 |
| **基准值** | **61%** 回 62 / **34%** 维持 64 / **5%** 进一步提高 |
| **宏观拟合** | 有全套交叉表：性别、年龄(5段)、职业(8类CSP)、学历(5级)、收入(5分位)、政治倾向(LFI→RN)、工会亲近度、2022/2024投票 → 可做按每个维度的排序一致性检验 |
| **细粒度建模** | 3-class 目标 (multinomial LR / XGBoost) + 8+ 画像特征 → SHAP 分析哪个特征对退休态度影响最大、年龄×职业交互效应 |
| **评分** | ⭐⭐⭐⭐⭐ |

### 2. 是否支持废除 2023 退休改革（回到 62 岁）

> **背景**：2023 年马克龙政府强行将退休年龄从 62 岁延至 64 岁，引发全国抗议。2025 年 IFOP 调查问法国人：如果就此举行全民公投，你会投票废除该改革（恢复 62 岁退休）还是保留（维持 64 岁）？

| | |
|---|---|
| **Prompt (FR)** | *"Si un référendum était organisé sur la réforme des retraites de 2023 qui a repoussé l'âge légal à 64 ans, voteriez-vous pour l'abroger (revenir à 62 ans) ou pour la conserver (rester à 64 ans) ?"* |
| **Prompt (ZH)** | 如果就 2023 年将法定退休年龄推迟到 64 岁的改革举行全民公投，您会投票废除它（回到 62 岁）还是保留它（维持 64 岁）？ |
| **数据源** | 同上 IFOP/CGT |
| **基准值** | **65%** 废除 / **35%** 保留 |
| **宏观拟合** | 同上全套交叉表 + 退休制度类型；年龄梯度(18-24 78%→65+ 41%)、职业梯度(工人 83%→高管 58%) 是非常好的检验锚点 |
| **细粒度建模** | 二分类 + 全特征 → ROC/AUC + 混淆矩阵；可做 cross-policy generalization（用此题模型预测#1 支持度） |
| **评分** | ⭐⭐⭐⭐⭐ |

## 三、细粒度建模为主（特征维度独特，宏观标杆相对弱）

这些调查的宏观交叉表不如 P0 退休调查详细，但提供了**独特的个体级变量**（如童年经历、企业规模、主观感知等），适合做探索性 ML 和文本分析。

### 15. 职场互助与企业收留无家可归者

| | |
|---|---|
| **Prompt (FR)** | *"Êtes-vous favorable à ce que les entreprises accueillent des sans-abris la nuit dans leurs locaux ?"* |
| **Prompt (ZH)** | 您是否支持企业在夜间将空置场所开放给无家可归者留宿？ |

## 六、建议实验路径（对应 brainstorm_extension.md 双线）

**Phase 1 — 宏观拟合**：退休三选一(#1) + 退休公投(#2) → 与 IFOP 交叉表逐维度对比 → 计算 Spearman/KL → 识别模型偏差模式

**Phase 2 — 细粒度建模**：头巾(#6) + 体罚(#7) + 工作到64(#3) → LR/XGBoost/MLP → SHAP → 找关键预测变量 → 与真实调查中已知的梯度方向对比（如"年龄是否应为头巾态度的最强预测变量"）

**Phase 3 — 双层整合**：用 #1 退休问题同时做宏观分布匹配 + ML 特征重要性 → 形成完整论证：LLM 模拟数据在宏观和微观层面各有多大可信度
