## 四项核心实验

### 实验 1: 跨模型对比 (`scripts/06_cross_model.py`)

**目的**: 验证 Prompt 敏感度、年龄独大、R² 天花板是否跨模型一致  
**设计**: 1000 画像 × 4+ 模型，同一 Prompt (Run 2)，对比立场分布/平均分/IFOP 差距  

**候选模型** (需切换平台后确认可用性):

| 优先级 | 模型 | 必要性 |
|--------|------|--------|
| 必做 | DeepSeek-V4-Flash (基准) | 与现有结果可比 |
| 必做 | DeepSeek-V3.2 | 同系列纵向对比 |
| 建议 | Qwen3.6-35B | 开源代表 |
| 建议 | GLM-5.1 | 中文能力对比 |
| 可选 | GPT-4o | 商业模型标杆 (需独立 API key) |
| 可选 | Claude 3.5 Sonnet | Anthropic 立场 (需独立 API key) |

**输出**: 立场分布对比表, 年龄-SHAP 跨模型一致性检验, 噪声/信号比跨模型对比  
**论文定位**: §4 新增 "Cross-Model Consistency" 节

---

### 实验 2: 重测信度 (`scripts/07_test_retest.py`)

**目的**: 直接测量 LLM 组内方差，将 R² 天花板从推导变为实证  
**设计**: 100 画像 × 5 次重复，顺序打乱，计算 σ_within、ICC(1)、噪声/信号比、立场一致率  

**关键检验**: 实测 σ_within² vs. R² 推导的 Var(ε) ≈ 2.6 × Var(f(x))  
**论文定位**: §4.5 补充实测验证数据，将推导升级为实证  

---

### 实验 3: 跨议题验证 (`scripts/08_cross_topic.py`)

**目的**: 验证"年龄独大"是退休议题专属还是跨议题普适规律  
**设计**: 1000 画像，移民政策问题，Run 2 Prompt 模板，年龄分组分析  

**关键检验**: 移民议题下 age |SHAP| 是否仍居首位？立场分布与退休议题的差异  
**论文定位**: §4.4 末尾短节 "Is Age-Dominance Topic-Specific?"

---

### 实验 4: 跨语言对比 (`scripts/09_cross_language.py`) — 新增

**目的**: 验证 Prompt 语言对 LLM 立场输出的影响  
**动机**: 当前使用中文 Prompt 询问法国人物画像的退休态度——这种语言不匹配是否混淆了结果？  
**设计**: 500 画像 × 3 语言 (中文 / 法语 / 英语)，同一 Run 2 模板，仅翻译指令框架和字段标签  

**关键检验**:
- 立场分布 (support/neutral/oppose) 是否因语言而变化？
- 同一画像跨语言立场一致率 → 若 < 80% 则语言是显著混淆因素
- 同一画像跨语言 Pearson r → 理想情况 r > 0.7
- 平均支持度差异 → 中文是否系统性地偏向某一立场？
- 法语 Prompt → LLM 训练数据中法语语料占比低 → 是否导致输出更不稳定？

**可能的发现**:
- 中文 vs 法语差异大 → 当前方法论有严重语言混淆，需讨论
- 三种语言结果一致 → 跨语言稳健性，支撑结论的通用性
- 法语-英语接近但中文偏移 → 英语语料在 LLM 训练中的主导地位

**论文定位**: §4 新增 "Does Language Matter?" 节，或作为 §4.1 Prompt Sensitivity 的延伸

## 平台切换

当前 `.env` 使用 **SiliconFlow** (`api.siliconflow.cn`)，可用模型: DeepSeek 系列、Qwen 系列、GLM 系列。GPT-4o / Claude 需独立 API key。

**切换时需确认**:
- 新平台的 RPM/TPM 限制
- 各模型兼容 OpenAI-compatible API 格式
- 预算: 06 (4模型 × 1000 = 4000次) + 07 (500次) + 08 (1000次) + 09 (1500次) ≈ **7000次调用**
- 是否需要调整 `call_llm.py` 中的 rate limiting 逻辑
